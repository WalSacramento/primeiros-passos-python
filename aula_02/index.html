Revisão · Repetição

E quando a mesma tarefa se repete?

No jogo de adivinhação, a pessoa tem até dez palpites. Escrever dez vezes as mesmas linhas seria cansativo e daria margem a erros.

Repetir é pedir ao computador que execute o mesmo bloco de instruções várias vezes. Hoje, vamos escrever essa repetição em Python.

pedir palpite→comparar→dar uma dica↺de novo

01 · Conceito de sorteio

Como o computador escolhe um número?

Python traz módulos: coleções de funções prontas, organizadas por assunto. O módulo random reúne funções de sorteio.

Para usá-lo, escrevemos import random no início do programa. Depois, random.randint(0, 100) sorteia um inteiro entre 0 e 100, incluindo os dois limites.

import random→random.randint(início, fim)→número sorteado

01 · Conceito de mais de dois caminhos

Um palpite, três respostas

Um palpite pode estar certo, abaixo ou acima do número. Com if e else, temos apenas dois caminhos.

elif significa “senão, se”. Ele testa uma nova condição quando as anteriores foram falsas. O programa segue somente o primeiro caminho verdadeiro, e else cobre o que sobrou.

if certo→elif abaixo→else acima

01 · Conceito de repetição

Repetindo um bloco com for

O comando for executa o bloco indentado uma vez para cada valor de uma sequência. A cada volta, a variável recebe o próximo valor.

range(1, 11) produz os inteiros de 1 a 10. O início entra e o fim não entra, por isso escrevemos 11 para chegar a 10.

for tentativa in range(1, 11):→tentativa vale 1, 2, …, 10

Assim como em if, os dois-pontos e a indentação marcam o bloco que será repetido.

01 · Conceito de interrupção

Parar antes da décima tentativa

Se a pessoa acertar no terceiro palpite, não faz sentido pedir outro. O comando break interrompe a repetição imediatamente, e o programa continua depois do bloco do for.

Ao final, precisamos saber se o jogo terminou por acerto ou por falta de tentativas. Para isso, guardamos um booleano: acertou = False antes do laço e acertou = True no acerto.

not acertou inverte o valor: é verdadeiro quando acertou é False.

01 · Adivinhação em Python

O programa completo

import random
numero = random.randint(0, 100)
acertou = False
for tentativa in range(1, 11):
    palpite = int(input(f"Tentativa {tentativa}/10 · seu palpite: "))
    if palpite == numero:
        print("Acertou!")
        acertou = True
        break
    elif palpite < numero:
        print("Seu palpite ficou abaixo do número.")
    else:
        print("Seu palpite ficou acima do número.")
if not acertou:
    print(f"Fim das tentativas. O número era {numero}.")

O sorteio fica antes do for para acontecer uma vez só. A mensagem final fica depois do bloco.

03 · Conceito de resto

Como saber se um número é par?

Um número é par quando a divisão por 2 não deixa resto. Quando o resto é 1, o número é ímpar.

Em Python, o operador % calcula o resto da divisão inteira. Por exemplo, 7 dividido por 2 dá 3 e sobra 1, então 7 % 2 vale 1.

número % 2 == 0 → par  ·  número % 2 == 1 → ímpar

06 · Conceito de contador

Uma variável que acumula

Um contador é uma variável que começa em zero e aumenta quando algo acontece. Ele precisa ser criado antes da repetição.

A atribuição pontos = pontos + 1 calcula o valor atual mais um e guarda o resultado na mesma variável.

pontos: 0→acerto: 1→erro: 1→acerto: 2

06 · Quiz em Python

Sorteio, repetição e pontuação

import random
pontos = 0
for pergunta in range(1, 6):
    fator1 = random.randint(1, 10)
    fator2 = random.randint(1, 10)
    resposta = int(input(f"Pergunta {pergunta}: {fator1} x {fator2} = "))
    if resposta == fator1 * fator2:
        print("Certo!")
        pontos = pontos + 1
    else:
        print(f"Errado. A resposta é {fator1 * fator2}.")
print(f"Pontuação final: {pontos} de 5")

Os fatores são sorteados dentro do for, então cada pergunta tem uma nova conta.
